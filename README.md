# 📊 Tableau Dashboard Project

## Overview
As part of my **Level 3 Data Technician Bootcamp with Leep Talent**, I developed an interactive Tableau dashboard to analyse and visualise real-world data. This project focused on transforming raw datasets into meaningful insights through dynamic dashboards, calculated fields, filters, and a range of visualisation techniques.

The dashboard allows users to explore trends, compare key metrics, and interact with data through intuitive visualisations, supporting data-driven decision-making and effective storytelling.

---

## 🎯 Project Objectives
- Clean and prepare data for visualisation.
- Create interactive dashboards to uncover patterns and trends.
- Present complex information in a clear and accessible format.
- Apply data visualisation best practices to support business insights.

## 📈 Visualisations Created
The dashboard includes a variety of chart types to support different analytical perspectives:

- 📊 **Bar Charts** – Compare values across categories.
- 📉 **Line Charts** – Identify trends and patterns over time.
- 🥧 **Pie Charts** – Display proportions and category distributions.
- 🗺️ **Map Visualisations** – Explore geographical trends and relationships.
- 🔍 **Scatter Plots** – Examine relationships between variables.
- 📋 **KPI Summary Cards** – Highlight key metrics at a glance.
